# FalsifyAI M3: simulation planner and restricted simulator

M3 asks whether H0 and H1 are quantitative enough to compute the selected observable. A qualitative change is not a numerical law. When the definitions are missing, the plan is `blocked` and the spec is null.

| Method | Path | Calls the model |
| --- | --- | --- |
| POST | `/api/v1/analyze/simulation-plan` | only when `mode=live` |
| POST | `/api/v1/simulate` | never |

The planner defaults to `mode=stub` and `reasoning_effort=medium`. Live mode does not fall back to the stub.

`/simulate` accepts a `SimulationSpec` and evaluates registered families: `constant`, `linear`, `quadratic`, and `exponential_decay`. It does not accept Python source. `delta` is `h1 - h0`, a difference of model predictions.

The mass-and-period hypothesis stays blocked in the stub because H1 names no quantitative mass dependence. The ideal pendulum equation for H0 does not fill that gap.

Earlier routes remain as described in [m2.md](m2.md).
