# FalsifyAI M0 guide

The current implemented milestone is M1. Parser and critic routes are documented in [m1.md](m1.md). This page remains the shell guide: process health, Meta Model API configuration, and the two scientific contracts.

The interactive reference is `GET /docs`. The same schema is also at `GET /redoc` and `GET /openapi.json`.

## Run

From the repository root, with Python 3.12:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python -m pytest
uvicorn app.main:app --app-dir backend --env-file .env --reload
```

Copy `.env.example` to `.env` and set `MODEL_API_KEY` only on your machine. The package does not open `.env` by itself. Uvicorn loads it when you pass `--env-file`. The test suite does not use that file and does not call the network.

## Endpoints

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/health` | Shell is running. Body is `status`, `service`, and `milestone`. |
| GET | `/help` | This contract as JSON. It does not echo the process environment. |
| GET | `/docs` | OpenAPI UI. |
| GET | `/redoc` | ReDoc UI. |

`/health` example:

```json
{"status": "ok", "service": "falsifyai", "milestone": "M4"}
```

## Configuration

| Variable | Required for | Rule |
| --- | --- | --- |
| `MODEL_API_KEY` | Live model calls only | Environment variable. The shell starts without it. Do not commit, log, or paste the value into source, tests, or docs. |
| `META_BASE_URL` | Live model calls | Absolute `https` URL. If the variable is absent, the shell uses `https://api.meta.ai/v1`. |
| `META_MODEL_ID` | Live model calls | Set it explicitly. `muse-spark-1.3` is the verified primary model. An empty value does not select a model. |

`StubModelProvider` is the default provider for the shell and for tests. `MetaModelProvider` refuses to initialize when the key is missing, the model id is missing, or the base URL is not absolute `https`. Its `complete` method still performs no HTTP in this milestone.

## Contracts

These objects are validated in code. M0 does not expose routes that accept them yet.

### HypothesisInput

| Field | Rule |
| --- | --- |
| `statement` | Required, 1–4000 characters after trimming. |
| `domain` | Optional, at most 200 characters. Blank is rejected. |
| `context` | Optional, at most 8000 characters. Blank is rejected. |
| `assumptions` | Up to 20 items. Each item is trimmed, non-blank, and at most 500 characters. |

Extra fields are rejected. A hypothesis cannot carry a verdict such as `NOT_YET_FALSIFIABLE`. That outcome belongs to a future judge.

### ScientificClaim

| Field | Rule |
| --- | --- |
| `statement` | Required, 1–4000 characters after trimming. |
| `origin` | `measured`, `literature-derived`, `assumed`, or `simulated`. |
| `epistemic_status` | `established`, `hypothesis`, `speculative`, or `unknown`. Established requires measured or literature-derived provenance. |
| `observable` | Required when `origin` is `measured`. |
| `source_ref` | Required when `origin` is `literature-derived`. Not used for `simulated`. |
| `spec_id` | Required with `routine_id` when `origin` is `simulated`. Lowercase identifier: a letter, then up to 63 letters, digits, or underscores. |
| `routine_id` | Same identifier rule as `spec_id`. Only a simulated claim may name either id. |
| `value` | Optional finite number. A boolean or a non-numeric string is rejected. |
| `unit` | Required whenever `value` is present. |

Nothing in the schema invents a measurement or runs a simulation. There is no field for code.

## Not in this milestone

Hypothesis Parser, Adversarial Critic, Null Model, Observable Designer, Simulator, Experiment Designer, Falsification Judge, frontend, database, DQ-12 demo, and Duffing demo.

DQ-12, if it is added later, is a speculative stress test and not established physics. A Duffing comparison, if it is added later, is an independent control.
