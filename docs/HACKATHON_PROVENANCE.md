# Hackathon provenance

FalsifyAI is new work for the Meta Global AI Developer Hackathon 2026, Indie Developer track, theme Push the Frontier. The event window is October 26–November 4, 2026.

The public repository history begins on October 26, 2026 with `M0: bootstrap backend, schemas, provider abstraction and tests`. Milestones M0 through M7 were implemented during that window. No earlier FalsifyAI codebase is included or described as hackathon work.

The existence of prior related adversarial-science projects does not represent pre-hackathon FalsifyAI implementation. FalsifyAI's software architecture, schemas, orchestration, simulator, UI, tests, and release implementation were built during the hackathon window. The general idea of adversarial scientific critique is not claimed as original to this project.

What was built during the event:

- the hypothesis parser, adversarial critic, null model, observable designer, restricted simulator, experiment designer, and falsification judge
- one orchestrated run and the judge-facing screen
- the Duffing synthetic control and the DQ-12 speculative stress test
- the single-origin release image

DQ-12 appears only as a speculative stress-test hypothesis. The release uses one public toy statement. It is input to be challenged. It is not established physics, and it is not a pre-existing FalsifyAI implementation.

The Duffing case is a synthetic quantitative control. Its equations and uncertainty are written in the hypothesis. The curves are model predictions, not experimental data.

Prior scientific ideas, including any earlier thinking about a frontier hypothesis, are domain material supplied to the instrument. They are not the FalsifyAI software.
