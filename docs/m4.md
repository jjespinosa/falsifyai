# FalsifyAI M4: experiment designer and falsification judge

M4 designs a controlled comparison and assigns one falsification status. A partial experiment is meaningful when the decisive resolution is still undefined.

| Method | Path | Calls the model |
| --- | --- | --- |
| POST | `/api/v1/analyze/experiment` | only when `mode=live` |
| POST | `/api/v1/analyze/judge` | only when `mode=live` |

Both default to `mode=stub` and `reasoning_effort=medium`. Live mode does not fall back to the stub.

The judge status is one of `TESTABLE`, `BELOW_SENSITIVITY`, `NON_DISCRIMINATING`, or `NOT_YET_FALSIFIABLE`. `TESTABLE` requires a quantitative comparison and a defined resolution. It does not mean the hypothesis is supported. `BELOW_SENSITIVITY` requires an explicit capability that is coarser than that resolution. `delta_over_sigma` stays null unless both a difference and an uncertainty were supplied.

The mass-and-period hypothesis is a partial experiment and `NOT_YET_FALSIFIABLE` in the stub, because H1 states no minimum effect. A blocked simulation does not by itself block the experiment. The design includes the sentence `No autonomous physical execution`.
