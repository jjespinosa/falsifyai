# Milestone M6

M6 adds two demonstrations to the pipeline that M5 already runs. It does not add a stage, a database, or a special verdict for either name.

`GET /health` and `GET /help` report milestone `M6`.

## Duffing benchmark

The Duffing card is a synthetic quantitative control. The hypothesis states the harmonic curve `Omega(A) = 1`, the weak Duffing curve `Omega(A) = 1 + 0.075 * A^2`, the domain `0 <= A <= 1`, and `sigma_Omega = 0.01`. Those numbers are model inputs. The screen labels the curves as a model prediction, not experimental data.

The restricted simulator evaluates the registered constant and quadratic families. It does not solve an ODE and it does not execute model-written code.

## DQ-12 stress test

The DQ-12 card is a speculative frontier stress test. It uses one public toy statement and no private notes. FalsifyAI tries to falsify that statement. The screen says it is a speculative hypothesis and that the run is adversarial.

An unexplained residual decoherence is not evidence for the claim. The twelve-dimensional separation is not replaced by ordinary three-dimensional distance. Without an operational map and a quantitative prediction, simulation stays blocked and the judge can return `NOT_YET_FALSIFIABLE`.

## Why two benchmarks?

Duffing shows that a fully specified quantitative model can travel through simulation and experimental discrimination. DQ-12 shows that the same system refuses to overclaim when a frontier hypothesis lacks that operational mapping or quantitative prediction.

## Manual canaries

Pytest does not call the network. The live checks are explicit:

```text
python scripts/live_m6_smoke.py duffing
python scripts/live_m6_smoke.py dq12
```

Each command sends one `POST /api/v1/run` with `reasoning_profile` `economy` and does not retry.
