# FalsifyAI M2: null model and observable

M2 builds a competing explanation and looks for a quantity that could separate it from the claim. It does not simulate, design a full experiment, or return a verdict.

| Method | Path | Default |
| --- | --- | --- |
| POST | `/api/v1/analyze/null-model` | `mode=stub` |
| POST | `/api/v1/analyze/observable` | `mode=stub` |

Both routes accept `reasoning_effort`. The M2 canary uses `medium`. `none` is rejected. Live mode does not fall back to the stub.

A null model may say that a conventional account can mimic the claim. An observable list may be empty when the definitions are not good enough. `discriminating: true` is not support for the hypothesis.

Parser and critic routes remain as described in [m1.md](m1.md).
